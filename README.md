# Kenali Mens by Fronstellar v2.4

Aplikasi web interaktif untuk pembelajaran siklus menstruasi dan perubahan fisiologis ovarium, uterus, endometrium, serta kontrol hormonal.

## Fitur utama

- Navigasi hari siklus, autoplay, kecepatan, dan panjang siklus yang dapat diubah.
- **Grafik enam hormon:** FSH, LH, estradiol, progesteron, inhibin A, inhibin B. Kurva adalah **indeks pola relatif (unit arbitrer)**, bukan kadar serum atau data pasien. Kurva dapat ditampilkan/disembunyikan satu per satu.
- Diagram interaktif **hipotalamus → GnRH → hipofisis anterior (FSH/LH) → ovarium**, termasuk umpan balik negatif dan positif menjelang ovulasi.
- Anotasi fisiologi yang mengikuti hari, termasuk seleksi folikel, LH surge, aktivitas korpus luteum, dan luteolisis.
- Anatomi ovarium dan perbesaran folikel antral dengan enam struktur yang dapat disorot: teka interna/eksterna, granulosa, antrum, kumulus ooforus, zona pelusida, dan oosit.
- Visualisasi uterus, tuba uterina, fimbriae, ovarium, serviks, vagina, serta tombol **Perbesar ilustrasi**.
- Skema lapisan endometrium dan simulasi peluruhan/pendarahan menstruasi H1–H5.
- **Floating Cycle Controller:** slider dan playback tersinkron, posisi preset atau manual, ukuran, mode ringkas, transparansi 55–100%, auto-hide 3/5/10 detik, dan snap-to-edge. Pengaturan disimpan di browser.
- Tema gelap/terang, 15 font, efek gerak yang bisa dinonaktifkan, dan dukungan reduced motion.

Fitur kuis, rangkuman konsep, tab validasi oogenesis, serta simulasi perjalanan/nasib oosit telah dihapus sesuai keputusan desain versi sebelumnya dan tidak dikembalikan.

## Penggunaan

Buka `index.html` di browser modern, atau aktifkan GitHub Pages dari branch `main` pada folder `/(root)`. Fungsi inti tidak membutuhkan backend; font Google memerlukan koneksi internet.

## Ketentuan ilmiah

Visualisasi bersifat skematis, bukan gambar anatomi dalam skala yang sebenarnya. Semua kurva dinormalisasi per hormon sebagai pola ilustratif sehingga amplitudo tidak dapat dibandingkan secara klinis. Hari ovulasi adalah perkiraan model, bukan prediksi siklus individu, kontrasepsi, atau alat diagnosis.
